4. Implementasi Praktikum

A. Gambar Responsif

Gambar berhasil ditampilkan dan menyesuaikan ukuran layar menggunakan max-width: 100% dan height: auto. Rasio gambar tetap terjaga sehingga gambar tidak terlihat melebar atau menyempit.

B. Kandidat Resolusi Gambar

Atribut srcset dan sizes berhasil diterapkan untuk menyediakan pilihan resolusi gambar. Pemilihan gambar diperiksa melalui DevTools menggunakan properti currentSrc.

C. Fluid Font

Fungsi CSS clamp() berhasil diterapkan untuk membuat ukuran judul menyesuaikan ukuran layar. Teks tetap terbaca pada ukuran viewport yang berbeda.

D. Container Query

Container query berhasil diterapkan pada pembungkus card. Perubahan ukuran container dapat memengaruhi tampilan card sesuai aturan CSS yang ditentukan.

E. Reduced Motion

Media query prefers-reduced-motion: reduce berhasil diterapkan untuk mengurangi atau menonaktifkan transisi dan animasi bagi pengguna yang memilih pengurangan gerakan.
